1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него ВСЁ содержимое этой папки (включая скрытую папку .github).
3. Вкладка Actions -> дождитесь зелёной галочки (10-15 минут).
4. Откройте завершённый запуск -> внизу Artifacts:
   VoiceChanger-android (app-release.apk) и VoiceChanger-windows (zip с voice_changer.exe).

Windows: поставьте VB-Cable, запустите voice_changer.exe, затем
Параметры -> Звук -> Микшер громкости -> для voice_changer выберите вывод "CABLE Input".
В Discord/игре выберите микрофон "CABLE Output".
